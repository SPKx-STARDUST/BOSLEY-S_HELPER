# 🐾 Bosley's Nutrition Intelligence

A modern pet nutrition search platform built for Bosley's Edward Crossing (Chilliwack, BC).

## Features
- 🐶 Dog & Cat nutrition database
- 🔍 Search by Protein, Fat, and Fiber levels
- 🥫 Kibble, Wet Food, and Treat filtering
- 🤖 NutriPaw AI Assistant
- 📱 Mobile-friendly responsive design
- ⚡ Instant nutrition recommendations

## Tech Stack
- React
- TypeScript
- Modern UI/UX

## Purpose
Help Bosley's staff and customers quickly find the best pet food based on nutritional needs.
